Abstract
The Covid-19 had a huge impact on different sectors in many countries and
such impact caused problems to many people around the world. Alleviation
in such pandemic can be solved by social distancing as well as putting on its
face mask. This small step of wearing a face mask as well as following social
distancing would save lots of lives as the spread of the virus could be mit-
igated. This project is implemented by considering these facts of Covid-19
protocols. The project aims to detect face mask, social distancing on video
feed and also reminder for vaccination by using deep learning models.
SSD algorithm is used for face mask detection and if mask is not wear then
recognition of face will be done by using face recognition algorithm. YOLO
object detection is used to detect the people in frame and distance is mea-
sured by using Euclidean formula. This project also has one more feature
that is detection for vaccination, so next dose will be calculated and reminder
will be sent to user.Also developed a desktop application where admin will
get notified and can monitor the violations. If violation happens, data will
get stored into firebase database and it will also notify admin. The desktop
application has features of viewing history of violated data, notification func-
tionality, user registration, etc. The overall accuracy of our system is above
90% depending on the quality of video we give as a input.
